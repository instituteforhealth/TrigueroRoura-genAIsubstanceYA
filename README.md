# Use of Generative Artificial Intelligence for Substance-related Information Among Young Adults (18–29) in the US

This repository contains the code required to reproduce the analyses presented in:

> Triguero Roura M, Mauro PM.  
> *Use of Generative Artificial Intelligence for Substance-related Information among Young Adults (18-29) in the US: A Cross-sectional Survey.*  
> **JMIR Formative Research.** 2026;100667 (forthcoming/in press).  
> DOI: https://doi.org/10.2196/100667  
> Preprint: https://preprints.jmir.org/preprint/100667

## Overview

This repository includes code for:

1. Reproducing all statistical analyses presented in the manuscript (analysis_final.R)
2. Generating American Community Survey (ACS) population estimates used to establish survey quotas during study design. (census_young_adult.R)

The repository does **not** include the survey dataset due to Institutional Review Board (IRB) restrictions. Researchers interested in accessing this data may contact the corresponding author.
